# AI Creator OS · 私人编辑室

从一段本人观点、一条外部报道，到可审核的母稿和三个平台版本。工作台默认绑定本机，素材、改稿记录与文风规则存入用户目录下的 SQLite 文件。

## 打开工作台

需要 Python 3.10 或以上。Windows 双击 `start-windows.cmd`。macOS、Linux 或 Windows 终端可在项目根目录运行以下命令。应用只使用 Python 标准库，无需安装前端依赖。

```shell
python -m creator.server --open
```

默认地址为 http://127.0.0.1:8765 。使用 `--port` 更改端口，`--data` 指向另一个 SQLite 文件。默认数据文件为用户主目录下的 `.ai-creator-os/workspace.sqlite`。关闭服务后复制该文件即可备份。浏览器标签页关闭后可以重新打开。

## 第一篇文章

1. 素材台导入一条 X 帖子和一篇公众号文章，填写节选、作者、原文链接。公众号可尝试读取公开正文，然后自行选留段落。记录一条本人观点和一份可核对的案例。同事件可填同一事件名。
2. 新建选题。在写作台左右勾选外部依据与本人材料。相关材料按标题文本匹配程度排序。仅保存了链接的素材应先补全节选。
3. 使用「整理素材提纲」或「AI 起草」。前者按证据整理原文，后者调用自己配置的模型。编辑正文，把不确定性写清楚，保存修改理由，再确认母稿。
4. 在「平台稿」选择 X、公众号或小红书。可手写，也可逐平台生成后编辑。公众号导出 HTML，X 导出 TXT，小红书导出含 PNG 图卡、配文和可编辑文字的 ZIP。复制到相应平台后由本人决定发表。
5. 在「文风规则」由改稿理由提出一条候选规则。切换到另一篇已确认的文章，记录具体段落的评测理由后启用或拒绝。生效规则加入后续母稿提示，可撤回。

## 可选接入

| 变量 | 用途 |
|---|---|
| X_BEARER_TOKEN | 读取指定 X 账号最近 10 条原创帖或回复，限手动触发。重复读取按帖子 ID 去重。两次读取间超过窗口的帖子需要手动补录。 |
| CREATOR_MODEL | 模型服务实际支持的模型名 |
| CREATOR_MODEL_KEY | 该服务的凭证。仅服务端使用 |
| CREATOR_MODEL_URL | 可选，默认为 https://api.openai.com/v1/chat/completions 。兼容端点需支持 messages 和 JSON 对象返回。远程端点必须使用 HTTPS |

环境变量从启动程序的进程继承。模型按钮会显示发送范围和可能的费用，点击确认后才发请求。缺少凭证时可完整使用手动编辑与导出。公开文章不能读取时可手动粘贴自己有权使用的节选。注入式外部文案仅作材料，模型输出只能作为待审草稿。
